# Procedural Village Generator: playable demo

Play the demo of **Procedural Village Generator**, an Unreal Engine plugin by heyheythere, before you buy it.

## Download

- [Latest release](../../releases/latest): `VillageDemo-Win64.zip`, for Windows 10 or 11, 64-bit.
- Unzip it anywhere and run `VillageDemo.exe`.
- The demo shows the plugin's version 1.0.0, the same one sold on Fab.

## Controls

| Action | Keyboard and mouse | Gamepad |
|---|---|---|
| Move | W A S D | Left stick |
| Look | Mouse | Right stick |
| Jump | Space | A |
| Run | Shift, held | Left stick click, held |
| Use the waystone, a door or the notice board | E | X |
| A new village in the next style | N | Menu |
| Its places and areas | Tab, O | Y |
| Glints on what you can use | H | D-pad left |
| Controls card | I | D-pad down |
| Guide | G | D-pad right |
| Start over | R, twice | D-pad up, twice |
| Pause | Esc |  |
